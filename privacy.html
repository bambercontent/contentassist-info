Privacy Policy

contentassist, last updated October 18, 2026

This policy covers the contentassist desktop application and this website. It separates what the application does today from what is only intended.

What the application handles today

  • From TikTok. After the owner signs in with a TikTok account they control, the application receives access and refresh tokens for that account and can read its basic profile (open ID, union ID, display name and avatar address) and request its own public video list. A short summary of the connection check is kept in a local database on the owner's computer. No other TikTok data is collected.
  • Credentials. The tokens and the application's client secret are kept on the owner's own computer, encrypted to the owner's Windows user account. The application does not write them to configuration files, logs, web pages or source control. TikTok states that access tokens last 24 hours and refresh tokens about a year.
  • Data flows. The application sends data only to TikTok's own authorization and API addresses. It has no advertising, no analytics and no tracking. It does not sell data or give it to third parties, and it does not send data to any AI service or train any model.
  • This website. It is a static page with no forms, scripts or analytics, and it collects nothing from visitors. Its hosting provider (GitHub Pages) may keep ordinary server logs, such as visitors' IP addresses, under the provider's own privacy statement. The application's owner does not use those logs.

Intended, not implemented

The owner intends to review public TikTok content for research. The application does not do this today. If it ever reads other TikTok data, that will be limited to what TikTok permits and the owner approves, and this policy will be updated first.

Sharing the owner chooses to do outside the application

Separately from the application's own data flows: if the owner chooses to copy or share results with an external AI service, including an assistant that runs in the cloud rather than on the owner's computer, that is the owner's own choice made outside the application, and that service's own terms and privacy practices apply. The client secret and tokens are never part of anything the owner shares, and the application does not display them.

Retention and deletion: three separate actions

  • Deleting stored credentials. The application's disconnect command deletes the stored client secret and tokens from the owner's computer. Nothing deletes them automatically: expired tokens stay on disk until the owner runs the command.
  • Deleting retrieved data. The local connection summary and anything else the application stores are kept until the owner deletes the local database files. The disconnect command does not delete them, and there is no automatic deletion.
  • Revoking access at TikTok. The owner can remove the application's access in TikTok's own settings for connected apps. That does not delete anything stored on the owner's computer, and deleting local files does not revoke access at TikTok.
