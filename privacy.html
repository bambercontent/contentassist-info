Privacy Policy

contentassist, last updated October 18, 2026

This policy covers the contentassist desktop application and this website. It separates what happens today from what is planned.

Today

  • No TikTok account data has been received. No sign-in with TikTok has been completed, so no tokens, profile details or video details exist.
  • Client secret. If the owner stores the app's client secret, it is typed into a hidden prompt and kept on the owner's own computer, encrypted to the owner's Windows user account. The application does not write it to configuration files, logs, web pages or source control.
  • This website. It is a static page with no forms, scripts or analytics, and it collects nothing from visitors. Its hosting provider (GitHub Pages) may keep ordinary server logs, such as visitors' IP addresses, under the provider's own privacy statement. The application's owner does not use those logs.

Planned (not available yet)

  • When the owner signs in with TikTok and consents, the application would receive access and refresh tokens for the owner's own account. TikTok states that access tokens last 24 hours and refresh tokens about a year. They would be stored on the owner's computer, encrypted to the owner's Windows user account.
  • It would then read the owner's open ID, display name, avatar and public video list with the counts TikTok returns (permissions user.info.basic and video.list only), and keep that information in a local database on the owner's computer, to show the owner how their own videos perform.
  • The application would send data only to TikTok's own authorization and API addresses. It has no advertising, no analytics and no tracking. It does not sell data or give it to third parties.
  • The application itself does not train or fine-tune any model on this data, and it does not send data to any AI service.

Sharing the owner chooses to do outside the application

Separately from the application's own data flows above: if the owner chooses to copy or share results with an external AI service, including an assistant that runs in the cloud rather than on the owner's computer, that is the owner's own choice made outside the application, and that service's own terms and privacy practices apply. The client secret and tokens are never part of anything the owner shares, and the application does not display them.

Retention and deletion: three separate actions

  • Deleting stored credentials. The application's disconnect command deletes the stored client secret and tokens from the owner's computer. Nothing deletes them automatically: expired tokens stay on disk until the owner runs the command.
  • Deleting retrieved data. Profile and video details, once the application stores any, are kept until the owner deletes the local database files. The disconnect command does not delete them, and there is no automatic deletion.
  • Revoking access at TikTok. The owner can remove the application's access in TikTok's own settings for connected apps. That does not delete anything stored on the owner's computer, and deleting local files does not revoke access at TikTok.
