contentassist

contentassist is a small desktop application that its owner runs on their own computer. It is built to connect to the owner's own TikTok account through TikTok Login Kit for Desktop, and then to read that account's basic profile details and public video list, so the owner can see how their own videos are performing. It is not a public service and has no other users. This website is only an information page for the application.

Legal pages: Terms of Service · Privacy Policy

Current status

In development. A TikTok sandbox has been set up for future testing, but so far the application has been tested only locally and offline: live TikTok authorization has not yet been tested. It has not been submitted to TikTok for review and it has not been approved by TikTok. No TikTok account data has been received by the application so far.

What works today

  • A local sign-in helper, built and tested on the owner's computer without contacting TikTok. It prepares the sign-in request the way TikTok's desktop documentation describes, listens for TikTok's response on the owner's own computer only, and can exchange the response for access tokens.
  • Encrypted local storage for the app's client secret and, once sign-in happens, its tokens, and a command that deletes them.

Planned, not available yet

  • After the owner signs in and gives consent on TikTok's own page, read the owner's open ID, display name and avatar (permission user.info.basic) and the owner's public video list with the counts TikTok returns (permission video.list). No other permissions are planned.

What it does not do

  • It does not post, edit, delete or message anything on TikTok.
  • It does not read any account other than the owner's own account.
  • It does not find or rank trends, hashtags, sounds or other people's videos.
  • This website does not collect information from visitors.
